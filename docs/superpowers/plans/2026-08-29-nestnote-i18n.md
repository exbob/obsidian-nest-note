# NestNote 中英界面语言 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** NestNote 界面按 Obsidian 语言在简体中文与英文之间切换；`zh*` 用简体中文，其余用英文。

**Architecture:** `src/i18n/` 提供 typed 文案表与 `t()`。加载时用 `getLanguage()`（缺失则 `localStorage.language`，再缺省 `en`）判定 locale 并缓存。UI 与服务直接调用 `t()`。测试用 `setLocaleForTests("zh")` 固定中文，避免宿主语言干扰。

**Tech Stack:** TypeScript、Obsidian API（`getLanguage` 运行时探测）、Vitest + happy-dom。无第三方 i18n 库。

## Global Constraints

- `minAppVersion` 保持 `1.5.0`；不把 `getLanguage` 当作编译期硬依赖。
- 不增加插件「界面语言」设置，不引入 i18next 等依赖。
- 语言代码大小写不敏感；以 `zh` 开头（含 `zh-TW`、`zh-cn`）→ `zh`，其余 → `en`。
- 不翻译：`NestNote`、命令 ID、`index.md`、`attachments/`、children 标记、Frontmatter 字段名。
- `FrontmatterParseError` / `ChildrenLinksError` 等内部英文错误保持英文；用户 Notice 外壳走 `t()`。
- 文案 key 必须与 spec 第 6 节表格完全一致。
- 现有测试通过 `tests/i18n-setup.ts` 固定 `zh`，不断言英文 UI。

`src/i18n/index.ts`：

```ts
import * as obsidianApi from "obsidian";
import { en } from "./en";
import { zh } from "./zh";
import type { MessageKey, UiLocale } from "./types";

export type { MessageKey, UiLocale } from "./types";
export { MESSAGE_KEYS } from "./types";
export { en } from "./en";
export { zh } from "./zh";

type LanguageApi = { getLanguage?: () => string };
type LanguageStorage = { getItem(key: string): string | null } | null;

const catalogs: Record<UiLocale, Record<MessageKey, string>> = { zh, en };

let localeOverride: UiLocale | null = null;
let cachedLocale: UiLocale | null = null;

export function resolveLocale(code: string | null | undefined): UiLocale {
  if (typeof code === "string" && code.trim().toLowerCase().startsWith("zh")) {
    return "zh";
  }
  return "en";
}

export function detectLanguage(
  api: LanguageApi = obsidianApi as LanguageApi,
  storage: LanguageStorage = defaultStorage(),
): string {
  if (typeof api.getLanguage === "function") {
    try {
      const code = api.getLanguage();
      if (typeof code === "string" && code.trim() !== "") {
        return code;
      }
    } catch {
      // Fall through to localStorage / default.
    }
  }
  const stored = storage?.getItem("language") ?? null;
  if (stored !== null && stored.trim() !== "") {
    return stored;
  }
  return "en";
}

export function currentLocale(): UiLocale {
  if (localeOverride !== null) {
    return localeOverride;
  }
  if (cachedLocale === null) {
    cachedLocale = resolveLocale(detectLanguage());
  }
  return cachedLocale;
}

export function setLocaleForTests(locale: UiLocale): void {
  localeOverride = locale;
}

export function t(
  key: MessageKey,
  vars?: Record<string, string | number>,
): string {
  return interpolate(catalogs[currentLocale()][key], vars);
}

function interpolate(
  template: string,
  vars?: Record<string, string | number>,
): string {
  if (vars === undefined) {
    return template;
  }
  return template.replace(/\{(\w+)\}/g, (match, name: string) => {
    const value = vars[name];
    return value === undefined ? match : String(value);
  });
}

function defaultStorage(): LanguageStorage {
  try {
    if (typeof localStorage === "undefined") {
      return null;
    }
    return localStorage;
  } catch {
    return null;
  }
}
```
