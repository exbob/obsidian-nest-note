# NestNote 文档行操作精简

## 目标

把 NestNote 面板每个文档行上的四个按钮精简为两个：常用的「新建子文档」保留在行上；不常用的「重命名」和「删除」收入「更多」菜单。点击文档名已经打开文档，因此去掉「打开」按钮。

## 行上控件

每个文档行的操作区只保留：

1. 「新建子文档」图标按钮（现有 `plus-circle`，行为不变）。
2. 「更多」图标按钮（`ellipsis-vertical`）。

展开/折叠 twistie 不属于操作区，保持原样。工具栏「新建文档 / 全部展开 / 刷新」不变。命令面板命令不变。

## 「更多」菜单

点击「更多」使用 Obsidian 原生 `Menu`，在鼠标位置弹出，菜单项为：

| 项 | 图标 | 行为 |
|----|------|------|
| 重命名 | `pencil` | 打开现有名称对话框，确认后调用 `documents.rename` |
| 删除 | `trash-2` | 打开现有删除确认对话框，确认后调用 `documents.trash` |

不自绘下拉、不增加右键菜单、不把其他操作塞进菜单。

## 打开文档

唯一打开入口是点击 `.nestnote-name`。行上不再渲染 `aria-label="打开"` 的按钮。

## 测试与文档

- 行操作可访问标签为「新建子文档」和「更多」。
- 重命名、删除测试先点「更多」，再点对应菜单项。
- 删除仍须确认，失败时保留侧边栏状态。
- README 侧边栏操作表改为：重命名/删除经「更多」菜单。
